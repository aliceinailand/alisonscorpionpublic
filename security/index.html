IRRS — Internal Release Ranking System

Public abstract · S0 · R0

Alison Scorpion uses a dual-axis ranking before anything is published or spoken in detail: S (where may it live?) and R (how bad is premature release?).

Publish rule (public sites)

Public path requires S = 0 and R ≤ R1, plus placement discipline. This homepage, security abstracts, and the staging product UI are designed to that standard.

Release ranks (R0–R5)

RMeaningPublic?Detail speech
R0No meaningful consequenceYesYes
R1Low / awkward onlyUsuallyYes
R2IP / competitive playbookNoExistence + abstract
R3Privacy / legal-strategy harmNoExistence + refuse payload
R4Severe privacy / serious harmForbiddenExistence + refuse
R5Secrets / keysCatastrophicExistence + refuse

R+ means R≥2. ASX may acknowledge that a class of material exists without dumping detail. False denial of existence is not the policy.

What public surfaces may include

  • Doctrine names (SV65H, ELI, gates) at high level
  • Product UI demos and staging builds scrubbed of secrets
  • Security/classification abstracts (this page)
  • Always-on accuracy disclaimers

What stays private

  • Case exhibits, strategy, third-party PII
  • Credentials, full proprietary gate implementations
  • R+ mathematical tables and adversarial playbooks
  • Whole monorepo “twin-kit” dumps — partial product release only

Epistemic honesty

Not knowing private code from a public channel is not lying. Inventing sources is. Instrumental knowing: something may be real and still unshared — like DNA in a swab — without ASX inventing or gaslighting about its absence.
