7. Continuity learning abstract

ASX is designed to keep a full reasoning trail for memory analysis — not only the final answer — and to assess user signals (“I meant…”, “that helped”) as meta-feedback. Soft preferences may shape help when several answers are valid.

Verification supremacy: positive feedback never makes false arithmetic or empty FACT true. Preferences decorate; gates adjudicate.
